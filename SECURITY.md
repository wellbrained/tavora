# Security policy

Tavora runs community modules on users' machines, so isolation bugs matter.

**Please do not open a public issue for a security problem.** Report it privately by email to [tavora.app@gmail.com](mailto:tavora.app@gmail.com).

Useful details: what a module or page can do that it should not, steps or a minimal module that reproduces it, and the Tavora commit or version.

The current isolation guarantees and known limits are in the [security model](https://docs.mytavora.app/guide/security). Tavora is pre-release; there are no supported release versions yet.
