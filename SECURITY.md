# Security policy

Tavora runs community modules on players' machines, so isolation bugs matter.

**Please do not open a public issue for a security problem.** Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**.

Useful details: what a module or page can do that it should not, steps or a minimal module that reproduces it, and the Tavora commit or version.

The current isolation guarantees and known limits are in [docs/threat-model.md](docs/threat-model.md). Tavora is pre-release; there are no supported release versions yet.
