# Module library

Add module opens separately at the Settings size: 1040 × 760, capped at viewport minus 48 px. It preserves the workspace slot and grant flow. Manage modules opens Settings > Modules.

The sidebar searches installed modules by name, description or id and filters their source. The fixed header offers All / In this workspace / Not in this workspace. Counts represent distinct modules, not panel instances. Filter counts respect search and source; source counts respect search and workspace filter. A scrolling column groups by source and sorts names alphabetically. Rows show the number of panels already open and offer Add another. Unsupported modules show a reason and disabled action. Empty results offer Show all modules.

Designed for 80+ modules with about ten added to a workspace. No remote catalogue is introduced. English and German labels are provided. Narrow windows stack the sidebar above the list.
