# Several frames at once, and undo for everything

- Ctrl or Shift and a click picks several frames on the Overlay page; drawing a box on the empty canvas picks every frame it touches.
- Move, hide, reset or remove them together. The Settings box changes Show, Opacity and Hide from capture on all of them.
- Undo and redo now cover everything on the page: adding, removing, hiding, Move to… and the settings. A removed frame comes back exactly as it was.
- An empty setup tells you where to add something.
