# Tidier Settings

- Every settings page starts right under its title, with thin scrollbars that no longer push the rows around.
- Section labels are quiet grey instead of amber, and a label that only repeats the page title is gone.
- Settings > Modules keeps Check for updates in view; the module library, Install zip, Open folder and Reload sit under More.
- Removing a module from a workspace asks first and says that its data stays.
- The panel menu only shows Split, Move and Maximize when they work.
- Backups has its own Your data group in Settings > About.
