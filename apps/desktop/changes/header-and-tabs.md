# Header and tabs, tidier

- Header icons share one size and a crisp line, and Layouts has a focus ring and the same hover as the others.
- Stop is red only while overlays show over a game; while they wait for one it stays plain with a blue dot. Start stays green.
- The arrow next to Add module is always there, so the header does not change size when the first panel opens.
- A tab shows its close button on the open tab, and on the others when you point at them.
- Clock and Counter shows one way to add the first item.
