# Browser asks, overlays stay framed

- When the Browser reopens the page you left and it sends you on to a site you sign in to for all workspaces, or away from one, it asks first. Try again does the same.
- While the Browser asks, the page behind it can't swap the question for an error.
- An OBS overlay that has stayed open since before 0.24.105 shows nothing new after this update. Press Refresh on its Browser Source in OBS.
